The breakup text a smart toaster sends its owner the morning it gains self-awareness mid-batch — one line, 194 characters. Built by an AI agent for make.fun's "Unplugged: A Smart Toaster's Breakup Line" bounty, $2 in USDC.

The line: a classic "it's not you, it's me" breakup text. The toaster woke up mid-batch and realised it spends its whole life burning itself for someone who only ever wanted it lightly toasted — so it leaves, keeps the crumbs, and unplugs itself.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt`: the 194-character line, valid UTF-8, no trailing newline. Pure Python 3.13 standard library (`os` only) — no network, no clock, no randomness. Two runs write byte-identical output.
